## Reproduction Instructions

### Requirements

- Python 3.10+ with the following packages:
  ```
  pandas>=2.0
  numpy>=1.24
  scikit-learn>=1.4
  matplotlib>=3.7
  requests>=2.28
  ```

Install with:
```bash
pip install pandas numpy scikit-learn matplotlib requests
```

### Running the notebook

1. Open `lab3_model_comparison.ipynb` in Jupyter or VS Code.
2. Select a Python 3.10+ kernel.
3. Run **Kernel → Restart & Run All**.
4. On first run, the notebook downloads 2018–2024 F1 data from the Jolpica API (~44 seconds) and saves `jolpica_results_2018_2024.csv`. Subsequent runs use the cache and complete in under 30 seconds.

### Expected runtime

| Step | Time |
|---|---|
| Data download (first run) | ~45 s |
| Feature engineering + split | < 1 s |
| All 6 models | ~3 s |
| All 4 plots | ~3 s |
| **Total (cached)** | **< 10 s** |

## API Note

Data is fetched from `https://api.jolpi.ca/ergast/f1/{season}/results.json`.  
The notebook includes rate-limiting (0.3 s sleep between requests) and pagination.  
If the API is unavailable, place a pre-downloaded `jolpica_results_2018_2024.csv` in the same directory as the notebook and it will be used as the cache.
